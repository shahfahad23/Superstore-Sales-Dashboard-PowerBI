Superstore Sales Dashboard – Power BI

An interactive Power BI dashboard created to analyze and visualize Superstore sales data.

Dashboard Overview

This dashboard provides insights into:

- Total Sales
- Total Profit
- Total Quantity
- Total Customers
- Sales trends over time
- Top sub-categories by quantity sold
- Profit by category
- Profit by shipping mode
- Quantity by payment mode
- Interactive filtering by date, region, segment, ship mode, and city

Tools Used

- Power BI
- Data Visualization
- Data Analysis
- Microsoft Excel / CSV

Project Files

- "Superstore_Sales_Dashboard.pbix" — Power BI dashboard file
- "SuperStore_Sales_Dataset.csv" — Dataset used for analysis
- "Dashboard.PNG" — Dashboard preview

Project Objective

The objective of this project was to transform sales data into an interactive dashboard and identify useful business insights through
data visualization.
